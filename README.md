# 书斋 · 小说听书 App

无广告的小说阅读 + 听书应用。**三种形态同一份代码**：
1. **手机/电脑浏览器**：自部署服务模式（本目录 `启动小说书城.bat`），局域网即开即用
2. **iOS App**：Capacitor 封装，GitHub Actions 云端出未签名 IPA，**巨魔商店安装**，永久使用
3. **Android App**：同一工程云端出 APK（固定签名，新包直接覆盖安装）

App 内离线优先：书存手机本地（IndexedDB）；安卓内置 10 音色离线语音（Kokoro 子集化模型），在家自动用微软 Edge 神经语音（晓晓/云希），外出自动切系统语音。**打包步骤见 [BUILD.md](BUILD.md)**。

## 启动（浏览器模式）

双击 `启动小说书城.bat`（或 `node server.js`），默认端口 **9324**。

- 本机：http://localhost:9324
- 手机（同一 WiFi）：http://192.168.0.205:9324

手机首次使用：Safari 打开地址 → 分享 → 添加到主屏幕 → 从桌面图标全屏启动。

## 功能

- **书架**：导入本地 TXT（手机文件选择器 / 电脑拖拽 / 直链导入），自动识别 UTF-8 / GBK / GB18030 / UTF-16 编码，按「第X章」自动分章；书名搜索、按最近阅读排序、今日阅读时长统计（番茄式）
- **阅读**：四种翻页方式（覆盖 / 平移 / 无动画 / 上下滚动，番茄式）——滑动手势 / 点左或右 1/3 屏幕 / 键盘方向键，**末页继续向后无缝进入下一章、首页向前回上一章末页**；沉浸式满屏阅读，点屏幕中间呼出菜单（上一章/进度滑条/下一章 + 全书进度条 + 目录正倒序/听书/设置/夜间）；四主题、字号/行距/字距/字体（默认·宋体·楷体）调节、自动阅读（10 档变速）、阅读期间屏幕常亮、进度自动保存恢复
- **听书**：安卓内置 10 个精选离线音色（Kokoro，晚晴/知夏/念安/疏影/青山/沉舟/远山/枫/阳/薇）+ 在线微软神经语音 + 系统音色三条链路自动降级；逐句浅色高亮跟随朗读位置，读到下一页自动翻页，段落自动连播、跨章续播，断流自动重试；定时关闭（按时间/按章节/自定义）
- **锁屏控制**：iPhone/安卓锁屏/控制中心可播放/暂停/上下段（MediaSession + 原生通知栏卡片）
- **兼容接口**：`GET /api/ra?text=&voiceName=&rate=` 与 tts-server 相同，外部工具可复用

## 架构

- `server.js` — Node 内置 http：书城 API + TTS + 静态托管，端口 9324
- `lib/parse.js` — 章节识别/段落切分（`test/parse.test.js` 7 项单测）
- `lib/encoding.js` — 编码探测（iconv-lite）
- `lib/tts.js` — Edge TTS 合成核心（每次请求新建连接 + 失败重试）
- `public/` — 前端（原生 HTML/CSS/JS，无构建步骤）
- `data/books/` — 书籍解析结果（JSON + TXT 原件），`data/progress.json` — 进度

## 说明与已知边界

- 电脑关机/睡眠后服务不可用；外网访问方案见 tts-server/README 的三个选项（云服务器/Cloudflare 隧道/路由器端口转发）
- iOS 锁屏续播依赖 Safari 媒体会话：锁屏后正常播完当前段并续播下一段；若长时间后台被系统回收，回到页面点播放继续（进度已保存）
- 书源爬虫未做（等于重写 Legado 且版权灰色），TXT 网上易得；直链导入可配合网盘直链使用
- 全部音频来自微软 Edge「大声朗读」免费接口，非官方调用，极少数情况可能限流（已内置重试）
